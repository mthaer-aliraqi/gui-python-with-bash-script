Python & PySide6 — Learn to Read & Write

دليل يشرح لماذا يعمل الكود وليس فقط ماذا تنسخ. اقرأ كل قسم بالترتيب، وفي النهاية ستجد مثالًا كاملًا جاهزًا.A guide that explains why code works, not just what to copy. Read each section in order; the final section has a complete ready-to-use example.

1. Python — Code Structure

بايثون تقرأ الملف من الأعلى إلى الأسفل، سطرًا سطرًا. لا توجد دالة main إجبارية مثل Java. الكود الذي تكتبه في مستوى الملف (بدون مسافة بادئة) يُنفَّذ مباشرة عند التشغيل.

الفرق الأهم عن Java: المسافات البادئة (Indentation) هي التي تحدد البلوكات، وليس الأقواس { }. 4 مسافات = مستوى جديد.

Python reads the file top to bottom, line by line. There is no mandatory main function like Java. Code written at the top level (no indentation) runs immediately.

The key difference from Java: indentation defines blocks, not braces { }. 4 spaces = a new level.

# 1) comment: any line starting with # is ignored
# 2) import: bring in a ready-made library
import math

# 3) top-level (global) variable
app_name = "MyTool"

# 4) function: starts with def, body is indented
def greet(name):
    # this line is inside the function (indent 4)
    print("hello", name)

# 5) program entry point: runs only when this file is executed directly
if __name__ == "__main__":
    greet(app_name)
    print(math.sqrt(16))

شرح كل سطرLine by line

السطرLineماذا يفعلWhat it does
import mathيحمل مكتبة الرياضيات الجاهزة لتستخدم math.sqrt.Loads the math library so you can use math.sqrt.
app_name = "MyTool"ينشئ متغيرًا نصيًا اسمه app_name. لا تحتاج لتحديد النوع.Creates a text variable named app_name. No type declaration needed.
def greet(name):يعرّف دالة تستقبل name. لم تُنفَّذ بعد.Defines a function that takes name. Not executed yet.
if __name__ == "__main__":"إذا كان هذا الملف هو المشغَّل مباشرة". عند استيراده من ملف آخر لن يُنفَّذ هذا الجزء."If this file is the one being run directly". If imported by another file, this block does not run.
greet(app_name)يستدعي الدالة ويمرر لها القيمة.Calls the function and passes the value.

قاعدة ذهبية: السطر ذو المسافة البادئة يتبع السطر الذي فوقه (def / if / for / class). عندما تعود للمسافة الأصلية ينتهي البلوك.

Golden rule: an indented line belongs to the line above it (def / if / for / class). When indentation returns to the original level, the block ends.

2. Variables, Types & Input/Output

المتغير اسم يشير إلى قيمة. بايثون تكتشف النوع تلقائيًا (Dynamic typing).

A variable is a name that refers to a value. Python detects the type automatically (dynamic typing).

name = "Ali"          # str   (text)
age = 25              # int   (whole number)
height = 1.78         # float (decimal number)
is_ready = True       # bool  (True / False)
nothing = None        # no value (like null)

print("name:", name, "age:", age)     # print
user = input("enter text: ")          # input always returns str

# f-string: easiest way to mix text and variables
print(f"{name} has {age} years")

# type conversion
number = int("42")      # text -> int
text = str(3.14)        # number -> text

انتبه: input() يرجع دائمًا نصًا. إذا أردت رقمًا استخدم int() أو float().

Careful: input() always returns text. If you need a number, use int() or float().

3. Conditions & Loops

score = 75

# conditions
if score >= 90:
    print("A")
elif score >= 70:      # elif = else if
    print("B")
else:
    print("C")

# for loop over a range
for i in range(3):           # 0, 1, 2
    print("i =", i)

fruits = ["apple", "banana"]
for f in fruits:
    print(f)

# while loop
count = 0
while count < 3:
    count += 1               # same as count = count + 1

# comparisons: ==  !=  <  >  <=  >=
# logic:       and  or  not
# membership:  in
if "apple" in fruits and not score < 50:
    print("found")

لا توجد ; في نهاية السطر، ولا { } للبلوكات، والنقطتان : تعني "ابدأ بلوك جديد بالمسافة البادئة".

No ; at the end of lines, no { } for blocks. The colon : means "a new indented block starts here".

4. Functions

# simple function
def add(a, b):
    return a + b          # return sends the value back to the caller

result = add(2, 3)        # result = 5

# default parameter
def hello(name="guest"):
    print("hello", name)

hello()                   # hello guest
hello("Sara")             # hello Sara

# any number of arguments
def total(*numbers):
    return sum(numbers)

print(total(1, 2, 3))     # 6

# type hints (optional, but helpful)
def square(x: int) -> int:
    return x * x

لاحظ: print() تطبع ولا ترجع قيمة. أما return فترجع القيمة. كثير من المبتدئين يخلطون بينهما.

Note: print() displays but does not return. return sends a value back. Many beginners confuse the two.

5. Classes (similar to Java)

الكلاس قالب (Blueprint). الـ self في بايثون يعادل this في Java، لكن يجب كتابته صراحةً كأول معامل في كل method.

A class is a blueprint. self in Python is the equivalent of this in Java, but it must be written explicitly as the first parameter of every method.

class Dog:
    # __init__ = constructor (runs when the object is created)
    def __init__(self, name):
        self.name = name       # attribute stored in the object

    # method needs self
    def bark(self):
        print(self.name, "says woof")

# create an object (no 'new' keyword)
d = Dog("Rex")
d.bark()          # Rex says woof

# inheritance
class Puppy(Dog):
    def bark(self):
        super().bark()          # call the parent's method
        print("(tiny voice)")

في PySide6 ستكتب كلاسات ترث من QWidget أو QMainWindow، وهو الأسلوب الأساسي للتطبيقات، كما تفعل في Java مع JFrame.

In PySide6 you will write classes that inherit from QWidget or QMainWindow. This is the main pattern for applications, similar to JFrame in Java.

# import everything from a module
import sys

لماذا if __name__ == "__main__":؟Why if __name__ == "__main__":?

بايثون تضع في __name__ القيمة "__main__" إذا كان الملف هو المشغَّل مباشرة، وتضع اسم الملف إذا تم استيراده. هذا يسمح بكتابة ملف يعمل كبرنامج ومكتبة معًا.

Python sets __name__ to "__main__" when the file is run directly, and to the module name when it is imported. This lets one file work both as a program and as a library.

8. Errors — try / except

try:
    n = int(input("number: "))
    print(10 / n)
except ValueError:
    print("that is not a number")
except ZeroDivisionError:
    print("cannot divide by zero")
finally:
    print("this always runs")

استخدم try فقط حول الأسطر التي قد تفشل: مدخلات المستخدم، الملفات، الشبكة، الأوامر الخارجية.

Use try only around lines that may fail: user input, files, network, external commands.

9. Running External Commands

مشروعك يشغّل سكربتات Bash، وهناك طريقتان:

Your project runs Bash scripts. There are two ways to do it:

import subprocess

# simple way: waits until the script finishes (freezes a GUI window!)
result = subprocess.run(
    ["sh", "hi.sh", "arg1", "arg2"],   # program first, then its arguments
    capture_output=True,               # capture stdout and stderr
    text=True                          # return text, not bytes
)
print(result.stdout)
print(result.stderr)
print(result.returncode)               # 0 = success

تنبيه: في تطبيق GUI لا تستخدم subprocess.run لسكربت طويل لأنه يجمّد الواجهة. استخدم QProcess (القسم 18) لأنه يعمل بالـ Signals وغير متزامن.

Warning: in a GUI app do not use subprocess.run for long scripts, because it freezes the window. Use QProcess (section 18), which is asynchronous and uses Signals.

Demonstrates QCheckBox and QRadioButton. The checkStateChanged signal fires when the state changes, and setVisible / setHidden show and hide widgets. on_radio changes the button text based on the selection.

16. Signals & Slots

هذا قلب Qt. العنصر يرسل إشارة، وأنت تربطها بدالة. يشبه setOnClickListener في Android لكن على مستوى أعم.

This is the heart of Qt. A widget emits a signal, and you connect it to a function. Similar to setOnClickListener in Android, but more general.

def on_click():
    print("clicked!")

btn.clicked.connect(on_click)            # connect a signal to a function
btn.clicked.connect(lambda: print("x"))  # anonymous function for simple cases

# receiving a value from the signal
def on_checked(checked):                 # toggled sends True/False
    print("state:", checked)

chk.toggled.connect(on_checked)

# remove a connection
btn.clicked.disconnect(on_click)

# emit manually (rare)
btn.click()

لماذا connect(on_click) بدون أقواس؟ لأنك تمرر الدالة نفسها كمرجع. لو كتبت on_click() ستنفذ الدالة فورًا عند هذا السطر وليس عند الضغط.

Why connect(on_click) without parentheses? Because you pass the function itself as a reference. Writing on_click() would run it immediately on that line instead of on click.

الإشارات الشائعةCommon signals

  • clicked — زرbutton
  • textChanged(str) — نص الحقل تغيّرfield text changed
  • returnPressed — ضغط EnterEnter pressed
  • toggled(bool) — checkbox / radio تغيّرcheckbox / radio changed
  • currentIndexChanged(int) — ComboBox
  • valueChanged(int) — Spin / Slider
  • readyReadStandardOutput — QProcess لديه مخرجاتQProcess has output
  • finished(int, ...) — QProcess انتهىQProcess finished

18. QProcess — Running Scripts Without Freezing the UI

subprocess.runQProcess
يجمّد الواجهة؟Freezes the UI?نعمYesلاNo
مخرجات مباشرة أثناء التشغيلLive output while runningلا (في النهاية)No (only at the end)نعم (عبر Signal)Yes (via a Signal)
مناسب لـ GUISuited for GUIلاNoنعمYes
from PySide6.QtCore import QProcess

self.process = QProcess(self)
# merge stdout and stderr into one stream
self.process.setProcessChannelMode(QProcess.ProcessChannelMode.MergedChannels)
self.process.readyReadStandardOutput.connect(self.on_output)
self.process.finished.connect(self.on_finished)

def run_script(self):
    # don't start a new script while the current one is running
    if self.process.state() != QProcess.ProcessState.NotRunning:
        return
    self.process.start("sh", ["hi.sh", "arg1", "arg2"])

def on_output(self):
    raw = self.process.readAllStandardOutput().data()
    text = raw.decode("utf-8", errors="replace")   # bytes -> str
    self.output.insertPlainText(text)

def on_finished(self, exit_code, exit_status):
    self.output.append(f"\n--- done (code {exit_code}) ---")

  • كتابة connect(func()) بدل connect(func).Writing connect(func()) instead of connect(func).
  • إنشاء نافذة قبل QApplication.Creating a window before QApplication.
  • نسيان self. على الـ widgets، فتُحذف عند انتهاء الدالة ولا تظهر.Forgetting self. on widgets, so they are deleted when the function ends and never appear.
  • استخدام subprocess.run داخل GUI لعملية طويلة.Using subprocess.run in a GUI for a long operation.
  • نسيان sys.exit(app.exec()) فتغلق النافذة فورًا.Forgetting sys.exit(app.exec()), so the window closes immediately.
  • تعديل الواجهة من Thread آخر. يُعدَّل الـ GUI من الـ Main Thread فقط، واستخدم Signals لنقل البيانات.Changing the UI from another thread. Only the main thread may touch the GUI; use Signals to pass data.
  • الـ Enum في PySide6 الحديث: اكتب Qt.AlignmentFlag.AlignCenter وليس Qt.AlignCenter القديمة.Modern PySide6 enums: write Qt.AlignmentFlag.AlignCenter, not the old Qt.AlignCenter.

QDialog (custom)

نافذة حوارية تصنعها بنفسك، مع أزرار OK / Cancel. exec() تفتحها بشكل مودال (تنتظر حتى تُغلق)، وترجع قيمة تدل على الزر الذي ضُغط.

A dialog window you build yourself, with OK / Cancel buttons. exec() opens it modally (the caller waits until it closes) and returns which button was pressed.

from PySide6.QtWidgets import (QDialog, QVBoxLayout, QLabel,
                               QLineEdit, QDialogButtonBox)

    def __init__(self, parent=None):
        super().__init__(parent)

        self.edit = QLineEdit()
        layout.addWidget(QLabel("Name:"))
        layout.addWidget(self.edit)

            QDialogButtonBox.StandardButton.Ok | QDialogButtonBox.StandardButton.Cancel
        )
        buttons.accepted.connect(self.accept)    # closes with Accepted
        buttons.rejected.connect(self.reject)    # closes with Rejected
        layout.addWidget(buttons)

# usage inside MainWindow
dlg = NameDialog(self)
if dlg.exec() == QDialog.DialogCode.Accepted:
    print("name:", dlg.edit.text())

23. ✅ Final Working Code

مثال كامل يجمع كل ما سبق بالطريقة الصحيحة: QMainWindow، Layouts، Signals/Slots، QProcess لتشغيل hi.sh، حماية من التشغيل المزدوج، واستخدام Enum الحديثة.

A complete example combining everything above the right way: QMainWindow, layouts, Signals/Slots, QProcess running hi.sh, protection against double runs, and modern enums.

import sys
from PySide6.QtCore import QProcess
from PySide6.QtWidgets import (
    QApplication, QMainWindow, QWidget,
    QVBoxLayout, QHBoxLayout,
    QLabel, QLineEdit, QPushButton,
    QCheckBox, QRadioButton, QTextEdit,
    QMessageBox
)


class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()                       # initialize Qt (required)
        self.setWindowTitle("PySide6 - final example")
        self.resize(520, 460)

        # ---------- 1) main container ----------
        central = QWidget()
        self.setCentralWidget(central)
        main_layout = QVBoxLayout(central)       # vertical arrangement

        # ---------- 2) input field ----------
        main_layout.addWidget(QLabel("Name:"))
        self.name_input = QLineEdit()
        self.name_input.setPlaceholderText("type your name")
        main_layout.addWidget(self.name_input)

        # ---------- 3) checkbox shows/hides the save button ----------
        self.check_box = QCheckBox("show save button")
        self.check_box.toggled.connect(self.on_checkbox)   # toggled sends bool
        main_layout.addWidget(self.check_box)

        self.save_btn = QPushButton("Save")
        self.save_btn.setVisible(False)                    # hidden at start
        self.save_btn.clicked.connect(self.on_save)
        main_layout.addWidget(self.save_btn)

        # ---------- 4) radio buttons (choose one) ----------
        radio_row = QHBoxLayout()                          # horizontal row
        self.rb1 = QRadioButton("Option 1")
        self.rb2 = QRadioButton("Option 2")
        self.rb1.setChecked(True)                          # default choice
        self.rb1.toggled.connect(self.on_radio)
        radio_row.addWidget(self.rb1)
        radio_row.addWidget(self.rb2)
        main_layout.addLayout(radio_row)                   # put the row in the column

        # ---------- 5) run-script button ----------
        self.run_btn = QPushButton("Run hi.sh")
        self.run_btn.clicked.connect(self.run_script)
        main_layout.addWidget(self.run_btn)

        # ---------- 6) output area (read-only) ----------
        self.output = QTextEdit()
        self.output.setReadOnly(True)
        main_layout.addWidget(self.output)

        # ---------- 7) QProcess runs the script without freezing the UI ----------
        self.process = QProcess(self)
        self.process.setProcessChannelMode(
            QProcess.ProcessChannelMode.MergedChannels     # stdout + stderr together
        )
        self.process.readyReadStandardOutput.connect(self.on_output_ready)
        self.process.finished.connect(self.on_finished)

    # ================= Slots =================

    def on_checkbox(self, checked):
        # checked is True or False
        self.save_btn.setVisible(checked)

    def on_radio(self, checked):
        # toggled fires for both buttons; react only when a button becomes selected
        if not checked:
            return
        self.run_btn.setText("Run hi.sh (Option 1)" if self.rb1.isChecked() else "Run hi.sh (Option 2)")

    def on_save(self):
        name = self.name_input.text().strip()     # strip: remove extra spaces
        if not name:
            QMessageBox.warning(self, "Error", "Please type a name first.")
            return
        QMessageBox.information(self, "Saved", f"Saved name: {name}")

    def run_script(self):
        # prevent starting a new script while another is still running
        if self.process.state() != QProcess.ProcessState.NotRunning:
            return

        name = self.name_input.text().strip() or "guest"
        self.output.clear()
        # program first, then its arguments. Change the path if hi.sh is elsewhere
        self.process.start("sh", ["hi.sh", "arg1", name])

    def on_output_ready(self):
        # called every time new output arrives
        raw = self.process.readAllStandardOutput().data()   # QByteArray -> bytes
        self.output.insertPlainText(raw.decode("utf-8", errors="replace"))

    def on_finished(self, exit_code, exit_status):
        self.output.append(f"\n--- finished (exit code: {exit_code}) ---")


# ================= Entry point =================
if __name__ == "__main__":
    app = QApplication(sys.argv)     # the app engine: create only once
    window = MainWindow()
    window.show()
    sys.exit(app.exec())             # event loop, always the last line
